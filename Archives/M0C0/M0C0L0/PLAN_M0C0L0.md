# Leçon Test : Rédiger du Code Robuste

## 1. Introduction au Code Robuste
On doit concevoir le code pour qu'il gère les cas d'erreur de manière proactive. Cela évite les plantages en production.

## 2. Règle clé : Ne jamais faire confiance aux entrées
Toute entrée externe doit être validée avant d'être traitée. C'est le premier rempart contre les failles de sécurité.

## 3. Exemple : Validation de schémas
L'utilisation de bibliothèques comme Pydantic ou Zod permet de valider la forme des données reçues en entrée.
