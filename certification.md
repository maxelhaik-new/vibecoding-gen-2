## Description

Dans les contextes d'innovation, de produit, de design, de marketing et d'entrepreneuriat, la transformation rapide d'idées en applications fonctionnelles devient une nécessité opérationnelle. Face à cet enjeu, les professionnels utilisent des outils d'IA générative pour concevoir, prototyper et déployer des produits numériques en autonomie, sans dépendre de développeurs ou d'outils no-code. Cette pratique, appelée **Vibe Coding**, permet de réduire les délais de création, d'accélérer l'innovation et d'autonomiser les équipes non techniques. Les compétences certifiées couvrent le cycle complet : cadrage produit, génération et itération du code via prompts, intégration d'API, déploiement sécurisé et veille technologique.

---

## Modalités d'évaluation

### Épreuve 1 — Mise en situation professionnelle

Le candidat conçoit, développe et déploie une application web fonctionnelle répondant à un besoin utilisateur identifié. Il utilise un assistant d'IA générative (Claude, ChatGPT ou équivalent) et/ou une plateforme de génération de code assistée par IA (Cursor, Bolt.new, Lovable ou équivalent) pour générer le code, itérer le prototype et résoudre les problèmes techniques. L'application intègre au minimum une connexion API externe et une fonctionnalité d'authentification ou de persistance des données.

**Livrables attendus :**

- Dossier de cadrage produit
- Application web déployée et accessible en ligne
- Code source versionné sur GitHub
- Vidéo de présentation

### Épreuve 2 — QCM de connaissances

QCM de **50 questions** couvrant l'IA générative appliquée au développement, le prompt engineering, la sécurité, le déploiement, les outils émergents et les bonnes pratiques.

## Référentiel de compétences & critères d'évaluation

### C1 — Cadrer un produit numérique

*Traduire une idée en parcours utilisateur et fonctionnalités structurées afin de produire des instructions exploitables par une IA générative à l'aide de techniques de prompt engineering.*

<aside>
⭐

**CE1.1** — Le candidat identifie et formalise les besoins du produit à partir du brief

- Indicateur 1.1.1 : Le document de cadrage présente les objectifs du produit et les profils utilisateurs.
- Indicateur 1.1.2 : Les besoins fonctionnels sont classés par priorité et justifiés par des scénarios d'usage.
- Indicateur 1.1.3 : Les contraintes sont explicitées.
</aside>

<aside>
⭐

**CE1.2** — Le candidat structure le parcours utilisateur et les interactions clés

- Indicateur 1.2.1 : Le parcours utilisateur est illustré par un schéma ou diagramme.
- Indicateur 1.2.2 : Les fonctionnalités sont associées à chaque étape du parcours.
- Indicateur 1.2.3 : Les étapes du parcours s'enchaînent logiquement sans rupture fonctionnelle.
</aside>

<aside>
⭐

**CE1.3** — Le candidat définit le cadre technique initial du projet

- Indicateur 1.3.1 : Les règles de génération du code sont définies (fichiers de règles, base de connaissances ou instructions contextuelles).
- Indicateur 1.3.2 : Le contexte technique initial (stack, architecture cible, contraintes) est formalisé.
- Indicateur 1.3.3 : Les instructions structurantes sont adaptées à l'outil / agent IA utilisé.
</aside>

<aside>
⭐

**CE1.4** — Le prompt produit présente une structure complète et exploitable par une IA générative

- Indicateur 1.4.1 : Le prompt comporte les instructions de rôle, objectif et contexte.
- Indicateur 1.4.2 : Les contraintes techniques et de style sont explicitées.
- Indicateur 1.4.3 : Le prompt contient des critères de validation du résultat attendu.
</aside>

### C2 — Générer et itérer un prototype fonctionnel

*Par cycles successifs d'interaction avec l'IA générative afin d'obtenir un produit stable et cohérent en appliquant des correctifs, retours en arrière (rollbacks) et ajustements guidés.*

<aside>
⭐

**CE2.1** — Le candidat pilote la résolution des erreurs et l'optimisation du code en adaptant sa stratégie de prompting face aux réponses de l'IA

- Indicateur 2.1.1 : Lors de la présentation ou dans la documentation, le candidat identifie une erreur complexe ou une hallucination survenue pendant le projet et justifie la stratégie de correction employée (réécriture du prompt, ajout de contexte, décomposition de la tâche).
- Indicateur 2.1.2 : L'historique des versions démontre des itérations successives ayant permis d'aligner la solution technique sur les besoins initiaux.
</aside>

<aside>
⭐

**CE2.2** — Le prototype final présenté est stable et fonctionnel

- Indicateur 2.2.1 : L'application fonctionne sans erreur bloquante.
- Indicateur 2.2.2 : Les fonctionnalités attendues sont opérationnelles et accessibles sans erreur critique.
</aside>

⭐

- Indicateur 3.1.3 : Les modifications sont enregistrées, versionnées et synchronisées via un système de gestion de versions (Git avec commit, push, pull ou équivalent).

- Indicateur 3.2.2 : Un fichier README documente l'installation, la configuration et l'utilisation du projet.
- Indicateur 3.2.3 : Les fichiers de configuration et dépendances sont correctement référencés.

⭐

**CE3.3** — Le code est maintenable et transférable

## Glossaire

- **API** *(Application Programming Interface)* : Interface permettant à une application de communiquer avec d'autres services ou logiciels via des requêtes automatisées.
- **MCP** *(Model Context Protocol)* : Interface permettant à l'IA de lire les API d'applications tierces.
- **Déploiement** : Action de rendre une application accessible en ligne sur un serveur ou une plateforme d'hébergement (Vercel, Netlify, Render…).
- **Environnement de développement local** : Espace de travail installé sur l'ordinateur du développeur pour exécuter, tester et modifier le code avant la mise en ligne.
- **IA générative** : Type d'intelligence artificielle capable de produire du contenu (texte, code, image…) à partir d'instructions humaines.
- **Itération** : Cycle d'amélioration successif d'un prototype ou d'un produit, basé sur des tests et retours.
- **Prompt / Prompt Engineering** : Technique consistant à formuler des instructions précises et structurées pour obtenir des résultats pertinents d'une IA générative.
- **Rollback** : Retour à une version précédente du code ou de l'application pour corriger une erreur ou restaurer un état stable.
- **Vibe Coding** : Pratique consistant à concevoir, générer et déployer des applications en s'appuyant sur des outils d'IA générative, sans nécessiter de compétences de développement avancées.
