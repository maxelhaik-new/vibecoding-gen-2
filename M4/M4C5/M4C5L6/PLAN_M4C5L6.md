# Plan M4C5L6 — Étendre les capacités de son agent avec les SKILLS

Type: logiciel
Status: draft

## Objectifs pédagogiques
- Comprendre ce qu'est un Skill dans Antigravity / Cursor / Vibe Coding (expertise métier, consignes & workflows pré-packagés).
- Différencier les capacités de base de l'agent (fichiers, terminal) d'un Skill (savoir-faire spécialisé).
- Découvrir des exemples concrets et réputés de Skills utiles (Audit Juridique/RGPD, Design Mobile / UI UX, Documentation API, SEO, etc.).
- Savoir où trouver des Skills pertinentes et de qualité (hub, dépôts, GitHub).
- Apprendre à configurer et activer un Skill pour étendre l'agent.

## Découpage des slides souhaité
1. **Titre & Introduction** : Présentation du sujet "Étendre les capacités de son agent avec les SKILLS".
2. **C'est quoi un Skill ?** : Un module de compétences métiers pré-configuré (workflows + connaissances + consignes) qui donne une expertise ciblée à l'agent.
3. **Capacités de base vs SKILLS** : Distinguer les outils natifs de l'agent (lire des fichiers, lancer le terminal) des SKILLS qui apportent la méthodologie et le cadre métier.
4. **Exemples de Skills réputés et cas d'usage** :
   - Design Mobile & UI/UX (ex: Tailwind UI Master, Mobile UX System)
   - Conformité & Audit Juridique / RGPD (ex: RGPD Compliance Audit, Legal Advisor)
   - Code Review & Sécurité (ex: Security Hardening, Clean Code Refactoring)
   - SEO & Rédaction technique (ex: Technical SEO Auditor)
5. **Où trouver des Skills pertinentes ?** : Dépôts recommandés, GitHub, écosystème Antigravity / Agent Skills.
6. **Comment installer & activer un Skill dans Antigravity** : Pas à pas simple pour un débutant.
7. **Bonnes pratiques & Sécurité** : Vérification des consignes, révision humaine des actions générées.
8. **Conclusion & Exercice pratique** : Synthèse et recommandation de test.
