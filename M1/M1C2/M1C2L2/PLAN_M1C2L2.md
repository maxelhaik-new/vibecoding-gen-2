# Leçon M1C2L2 : Définir le Vibe Coding

## 1. Qu'est-ce que le Vibe Coding ?
Le Vibe Coding désigne une pratique de développement où l'humain ne tape plus de syntaxe de code (HTML, CSS, Python, JS). Il interagit avec un agent IA en langage naturel pour décrire son intention. L'agent exécute les modifications directement dans le projet.

## 2. Le rôle du développeur
Le développeur passe d'un rôle d'exécutant syntaxique à un rôle de superviseur et d'architecte.
- On définit l'intention et le plan.
- On valide les propositions de l'agent.
- On oriente les choix et on gère la cohérence globale.

## 3. Les bénéfices majeurs
- Vitesse d'exécution décuplée.
- Élimination des erreurs de syntaxe simples.
- Focus sur la conception et l'expérience utilisateur plutôt que le débogage syntaxique.
