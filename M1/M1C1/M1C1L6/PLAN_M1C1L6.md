# Leçon M1C1L6 : Les mots du développeur — vocabulaire essentiel du Vibe Coding

## 1. Contexte pédagogique

Cette leçon a pour but de définir, de façon rassurante et progressive, les termes techniques incontournables rencontrés dans la formation. Elle s'adresse à un apprenant non-développeur qui découvre l'univers du code IA pour la première fois. L'objectif est de démystifier le jargon pour aborder la suite du parcours avec confiance, sans être bloqué par des mots inconnus. Le ton est bienveillant, la structure variée pour éviter la monotonie.

## 2. Termes couverts

- **Prompt** : L'instruction en langage naturel donnée à l'IA.
- **LLM / Modèle d'IA** : Le moteur probabiliste derrière l'intelligence artificielle.
- **IDE** : L'environnement de développement intégré — l'atelier de travail.
- **Stack** : L'ensemble des technologies qui composent une application.
- **Frontend / Backend** : La partie visible vs la partie invisible d'une app.
- **API** : Le connecteur universel entre deux services.
- **Base de données** : La mémoire persistante de l'application.
- **Git / Versioning** : Le système de sauvegarde et d'historique du code.
- **Déploiement** : Rendre une application accessible en ligne.
- **MVP** : Le produit minimum viable pour tester rapidement une idée.
