# Plan de la leçon M3C4L1 — Les objectifs du chapitre : Git & GitHub

Cette leçon présente les objectifs du Chapitre 4 du Module 3 consacré au versionning de code avec Git et au stockage distant sur GitHub.

**Slide 1 : VIBECODING - COVER CHAP**
* Titre : Git et GitHub : Le versionning de code

**Slide 2 : VIBECODING - OBJECTIF CHAP**
* Titre : Les objectifs du chapitre
* Intro : Ce chapitre introduit l'utilisation de Git et GitHub pour sauvegarder et versionner son code. On y apprend à gérer des branches et à collaborer efficacement avec l'IA.
* Titre 1 : Comprendre le principe du versionning Git
* Titre 2 : Initialiser un dépôt et faire son premier commit
* Titre 3 : Envoyer les fichiers locaux sur son dépôt GitHub
* Titre 4 : Créer et fusionner des branches de travail
* Titre 5 : Gérer les conflits de code avec l'aide de l'IA
* Titre 6 : Structurer proprement un projet open-source
