# Plan de la leçon M2C2L5 — Du besoin métier au cahier des charges minimal

Cette leçon enseigne de manière théorique comment compiler le Persona, le MVP et les User Stories dans un cahier des charges fonctionnel. Elle montre comment structurer ce document de référence sans parler de technique.

**Slide 1 : VIBECODING - COVER**
* Titre : Du besoin métier au cahier des charges

**Slide 2 : VIBECODING - INTRO**
* Présentation de la formalisation des exigences.
* 3 points : La compilation, Le format machine, Les 3 composants.

**Slide 3 : VIBECODING - CONCEPT**
* Pourquoi rédiger un cahier des charges (notion d'alignement, éviter l'improvisation de l'IA).

**Slide 4 : VIBECODING - 3 BLOCS - PHOTO**
* Les 3 composants du cahier des charges fonctionnel :
  1. Le Persona (Cible)
  2. Le Périmètre (MVP)
  3. Le Découpage (User Stories)

**Slide 5 : VIBECODING - USE CASE**
* Cas pratique du Mini CRM (commercial nomade) : compilation des 3 piliers.

**Slide 6 : VIBECODING - USE CASE**
