# Plan de la leçon M2C1L5 — Du LLM conversationnel au LLM de code

Cette leçon explique les différences fondamentales entre un LLM généraliste de type chatbot et un modèle spécialisé entraîné pour le code (logiciel).

## Découpage des Slides (8 slides)

1. **Slide 1 : Cover** (`VIBECODING - COVER`)
   - Titre : Du LLM conversationnel au LLM de code
2. **Slide 2 : Introduction** (`VIBECODING - INTRO`)
   - Présentation de la distinction entre les deux architectures et annonce des trois axes (entraînement brut, conscience spatiale, mécanismes natifs).
3. **Slide 3 : Définition** (`VIBECODING - DEFINITION`)
   - Définition d'un "LLM de code" et de ses capacités d'intégration de contexte.
4. **Slide 4 : Comparaison** (`VIBECODING - COMPARAISON`)
   - Tableau comparatif entre Chatbot (généraliste) et Code LLM sur 4 critères clés.
5. **Slide 5 : Concept** (`VIBECODING - CONCEPT`)
   - Focus sur la notion de conscience globale du projet (Repository-level) face aux limites de l'isolation du chatbot.
6. **Slide 6 : Processus** (`VIBECODING - PROCESS`)
   - Les étapes du fonctionnement du Fill-in-the-Middle (FIM) pour insérer des modifications précises sans corrompre le code.
7. **Slide 7 : Checklist** (`VIBECODING - CHECKLIST`)
   - Les points de vigilance et les limites inhérentes aux LLM de code (coûts, UX).
8. **Slide 8 : Synthèse** (`VIBECODING - FIN`)
   - Ce qu'il faut retenir et transition vers le cas pratique de configuration.
